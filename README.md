# BOAT RACE バックテストツール

競艇（ボートレース）公式データを使ったバックテストプロジェクトです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `download.py` | K/B LZH ファイル一括ダウンロード (3秒インターバル) |
| `parse.py` | K ファイル (成績) + B ファイル (番組) → SQLite 保存 |
| `backtest.py` | 複合スコアリングモデルによる戦略バックテスト |

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方

### 1. データダウンロード

```bash
# 直近7日分 (引数省略時)
python download.py

# 日付範囲指定 (YYYYMMDD)
python download.py 20260101 20260107
```

`data/lzh/` に K (競走成績) と B (番組表) の LZH を保存。
競走非開催日は HTTP 404 でスキップします。

### 2. データパース

```bash
python parse.py

# デバッグ出力 (生レコード確認)
python parse.py --debug
```

`data/boatrace.db` に以下のテーブルを作成:

| テーブル | 内容 |
|---|---|
| `races` | 開催レース (天候, 風速, 水温, 波高) |
| `results` | 艇別成績 (コース, 着順, タイム, ST) |
| `payouts` | 払戻金 (単勝/複勝/拡連複/2連複/2連単/3連複/3連単) |
| `entries` | 選手・モーター情報 (B ファイルがある場合) |

### 3. バックテスト

```bash
python backtest.py

# オプション
python backtest.py --bet 200        # 1点あたり ¥200
python backtest.py --history 50     # 直近50走でフォーム評価
```

## スコアリングモデル

選手・モーター・スタート・直近フォームを加重合算:

| 特徴量 | 重み | データソース |
|---|---|---|
| 当地勝率 | ×3.0 | B ファイル |
| 全国勝率 | ×2.0 | B ファイル |
| モーター2連率偏差 | ×1.5 | B ファイル |
| コース係数 | ×1.5 | 固定値 |
| 平均ST | ×-12 | B ファイル |
| F回数ペナルティ | ×-3 | B ファイル |
| 直近N走 1着率 | ×2.5 | K ファイル蓄積 |
| 直近N走 3着内率 | ×0.8 | K ファイル蓄積 |

B ファイルがない場合はコース係数と直近フォームのみで採点します。

## 比較戦略

| 戦略 | 概要 | 点数/レース |
|---|---|---|
| S1 単勝 | スコア1位に単勝 | 1点 |
| S2 3連複 | 上位3艇で3連複 | 1点 |
| S3 3連単BOX | 上位3艇を3連単BOX | 6点 |
| S4 2連単流し | 1位固定 × 2・3位へ2連単 | 2点 |
| S5 単勝バリュー | 1位 かつ 人気3位以下のみ賭け | 1点 |

## 注意事項

- 本ツールは教育・研究目的です
- 公式サイトへの過剰アクセスを避けるため3秒インターバルを設けています
- 固定長フォーマットのオフセット定数は `parse.py` 内の `KParser` / `BParser` クラスで管理。
  実データの `--debug` 出力と照合して必要に応じて調整してください
- バックテストの回収率は過去データへの過適合が起きやすいため、参考値としてください
